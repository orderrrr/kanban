## Goal

A neutral, readable look; keyboard use; works at phone width. Done when the user is happy with it.

## Plan

<!-- Written with the user when this ticket is claimed; approved once. -->
- [x] 1. Task text is clickable to edit in place (Enter saves, Escape cancels); no Rename button.
- [x] 2. Remove is a trash icon, shown only while hovering the task (or when it has keyboard focus).
- [x] 3. Checklists show at most 3 tasks, with "+n more"; hovering (or focus inside) expands them into a scrollable list of fixed height.
- [x] 4. The checklist's last line is where new tasks are typed: Enter adds one and leaves a fresh line. No Add button.
- [x] 5. Drag by pointer events (no library): the card or task lifts out of its place, follows the pointer, and a gap opens where it would land; dropping fills the gap, dropping elsewhere puts it back. Replaces the browser's own drag and drop.
- [x] 6. Keep the plain M4 look (the user prefers it; a restyle was tried and reverted); keyboard ways to move cards and tasks (Alt and the arrow keys); works at phone width.
- [x] 7. Tests, and a check in a real browser (Chromium headless shell) before the user looks; restart the preview after building.
- [x] 8. Milestone gate: `mr-review` and a `WEB_STYLE.md` pass, until clean.

## Answer

The board reads and edits plainly, in the M4 look. Task lines are text fields: click to edit, Enter adds a line below (with the status of the task above), Backspace on an empty line removes it, done tasks sit last. Tasks have three statuses stepped by their box. Checklists show three tasks and expand on hover, scrolling the window to show the whole card. Pencil, trash and grip show on hover (always on touch). Cards and tasks are carried by pointer with a gap where they will land, or moved with Alt and the arrows. Each ticket opens (`#DEV-1234`) into a board of its tasks by status. Names and titles are at most 64 characters. Works at phone width; dragging needs a pointer. 177 tests; checked in headless Chromium. Gate: four rounds, fixes in `775d456`, `a32b7c2`, `7213488`, `6dbc23b`, `65d7e10`. Deferred: on Windows and Linux, Alt with Left or Right in a card's line may make the browser go back; Backspace removing a column's only task leaves focus on the page.
