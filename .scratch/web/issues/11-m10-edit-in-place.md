## Plan

Approved by the user's choice of this direction on 04/11/2026.

- [x] 1. New tickets: the form goes; Backlog ends with a faint "+ New ticket" line shaped like an empty card. Clicking it opens a name field there; Enter adds the ticket with a generated ID and keeps the line open for the next; a name starting with a DEV ID ("DEV-2222 Dark mode") uses that ID. Escape, or leaving it empty, closes it. Dates come later, from the pencil.
- [x] 2. Editing: the pencil turns the card's own name and dates into fields where they sit, at their size: the name as a heading-sized box, the dates as one line (start "to" due) with a small × to clear them. No visible labels, no Save or Cancel: Enter or leaving the fields saves, Escape undoes. A warning shows only if one date is left alone.
- [x] 3. The open ticket's header edits the same way, at its larger size.
- [x] 4. Tests, a check in Chromium and Zen, and the milestone gate.
